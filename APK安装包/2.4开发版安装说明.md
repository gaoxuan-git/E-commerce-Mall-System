# 电商网购系统 2.4 开发版

安装文件：`电商网购系统-2.4-可配置IP开发版-移动适配.apk`，约 39 MB。

- 版本：2.4，Android versionCode：5。
- 包名：`com.dianshang.mall`。
- 使用原开发签名，支持覆盖安装目录中的旧版 APK。
- Android 原生 `debuggable=true`，支持 `armeabi-v7a` 和 `arm64-v8a`。
- 已包含搜索栏、分类、购物车、商品详情、账户菜单及服务器设置页的移动端布局适配。

## 连接开发环境

首次启动，在服务器连接页填写运行后端的电脑 IP。后续修改入口为“我的 → 左上角账户菜单 → 服务器连接设置”。

1. 手机和电脑连接同一局域网。
2. 协议填写 `HTTP`，服务器地址填写电脑 IP。
3. 商城端口填写 `8081`，图片端口填写 `8080`。
4. 点击连接检测，检测通过后保存。

打包时电脑 IP 为 `10.67.163.88`；IP 变化后可在 App 内修改。业务接口使用保存的服务器地址，首次未配置时先进入服务器连接页。

本地 `crmeb-admin`、`crmeb-front` 必须使用 `--spring.profiles.active=dev` 启动。已核对当前两个服务均为 `dev`：

- 短信验证码默认 `123456`，可由后端环境变量 `CRMEB_DEV_SMS_CODE` 覆盖。
- 开发环境模拟支付和模拟充值开启；App 读取所连接后端返回的开发支付配置。
- 验证码和模拟支付能力由后端环境决定，迁移电脑后仍需使用 `dev` 启动。
