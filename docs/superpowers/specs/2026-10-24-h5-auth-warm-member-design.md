# H5 登录注册页轻盈会员风设计

## 目标

在不改变现有认证接口、业务流程和页面路由的前提下，重做 H5 登录注册页的视觉层次与表单体验，使其与当前商城个人中心的暖色主题保持一致，并去除旧品牌图片依赖。

## 范围

本次仅修改：

- `frontend/uni-app/pages/users/login/index.vue`

保留并复用：

- 手机验证码登录
- 手机号密码登录
- 手机号注册
- 短信验证码发送与倒计时
- 行为验证码
- 用户协议和隐私政策跳转
- App 微信与 Apple 登录
- 登录成功后的用户信息获取与返回逻辑

不修改认证 API、Pinia 状态、路由配置、后端代码或用户数据。

## 已确认方向

采用可视化方案 C“轻盈会员型”：

- 页面使用暖白背景，橙色作为主要强调色，深色作为主按钮和正文颜色。
- 顶部固定显示中性文字标识“商城系统”，不读取 `mobileLoginLogo` 作为页面品牌展示。
- 使用简洁几何色块形成视觉重点，不使用宣传图片、旧品牌素材或复杂插画。
- 欢迎区与表单区保持连续布局，不使用嵌套卡片。
- 默认展示验证码登录，密码登录作为同一登录标签内的次级模式。

## 页面结构

### 顶部区域

- 适配安全区和 H5 浏览器顶部空间。
- 显示“商城系统”文字标识。
- 登录状态文案为“回来看看，喜欢的都在”。
- 注册状态文案切换为“第一次见，欢迎加入”。
- 辅助文案说明订单、收藏和会员权益会在登录后同步。
- 使用 CSS 几何色块作为装饰，装饰层不可遮挡文字或交互控件。

### 模式切换

- 一级切换为“登录 / 注册”。
- 登录模式下提供“验证码登录 / 密码登录”次级切换。
- 默认进入验证码登录。
- 切换一级模式时继续清空验证码、密码和确认密码，沿用当前行为。
- 所有切换控件保持固定高度，切换时不得引起页面横向位移。

### 表单

- 输入框统一高度、圆角、内边距和聚焦状态。
- 手机号输入框在三种模式中保持一致。
- 验证码按钮位于验证码输入框右侧，保留倒计时和禁用状态。
- 密码登录展示手机号和密码。
- 注册展示手机号、短信验证码、密码和确认密码，保持单页完成注册。
- 图标使用项目现有字体图标或纯 CSS，不依赖远程登录图标图片。

### 协议和操作

- 协议勾选区紧邻主按钮上方。
- “用户协议”和“隐私政策”保持可独立点击。
- 登录主按钮文案为“登录”。
- 注册主按钮文案为“注册并登录”。
- 主按钮禁用、发送验证码中和第三方登录状态沿用现有逻辑。
- App 端第三方登录区域保留在主表单之后，视觉样式与新页面统一。

## 视觉规范

- 页面背景：暖白色，不使用大面积单一橙色。
- 强调色：继续通过 `var(--view-theme)` 接收商城主题色，默认使用暖橙色。
- 正文色：接近黑色的暖灰。
- 辅助文字：中性灰褐色。
- 表单圆角不超过 `8px`，主按钮使用胶囊形状以突出主要命令。
- 字号不随视口宽度缩放。
- 字间距固定为 `0`。
- 页面内容适配 `375px` 至 `430px` 宽度，并考虑注册表单在矮屏上的自然滚动。

## 数据和错误处理

- 保留现有 `account`、`password`、`confirmPassword`、`captcha`、`formItem` 和 `current` 状态。
- 保留当前接口调用、手机号格式检查、协议检查、密码一致性检查和错误提示。
- 保留滑块验证码成功后的短信发送流程。
- 样式调整不得吞掉接口错误、修改 Toast 文案或绕过协议确认。
- 远程配置或图片域名不可用时，页面仍应依靠本地样式完整显示。

## 验收标准

- H5 登录页首屏显示中性“商城系统”标识，不显示旧登录 Logo。
- 默认打开验证码登录。
- 登录、注册、验证码登录和密码登录之间可正常切换。
- 注册模式完整展示手机号、验证码、密码和确认密码。
- 协议勾选、协议链接、验证码发送和主按钮行为保持正常。
- App 微信与 Apple 登录入口在满足原有条件时仍可使用。
- `390×844`、`375×812` 和 `430×932` 视口无横向溢出、文本遮挡或控件跳动。
- `npm run build:h5` 构建成功。
- Playwright 登录页与注册页截图检查通过。

## 非目标

- 不新增找回密码、第三方账号绑定或多步骤注册。
- 不修改用户中心、账号抽屉或其他授权页面。
- 不调整后端认证策略、验证码规则或协议内容。
