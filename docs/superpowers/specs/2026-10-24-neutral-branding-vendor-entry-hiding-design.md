# 中性品牌展示与厂商入口隐藏设计

## 目标

将管理后台与 H5 中面向用户展示的 CRMEB、开源版本、企业宣传和具体版本信息替换为中性商城文案，并隐藏当前项目不使用的厂商服务入口。

本次调整不得删除或破坏业务页面、接口、路由、权限和数据库记录。

## 展示调整

### 管理后台登录页

- 不再展示包含“JAVA 开源版”和企业宣传语的轮播素材。
- 不再展示 CRMEB 图片 Logo 和 `CRMEB-JAVA-KY-v3.1` 等版本信息。
- 使用“商城管理后台”作为中性名称。
- 复用现有无文字插画或背景素材，不引入新的厂商品牌内容。

### 管理后台

- 浏览器标题默认值改为“商城管理后台”。
- 首页欢迎语改为“欢迎使用商城管理后台，祝您工作愉快！”。
- 不展示厂商版权或版本页脚。

### H5

- 个人中心不展示 CRMEB 厂商版权图片。
- 可见的 CRMEB 默认名称改为“商城系统”。
- 不改源码许可证与版权注释，因为这些内容不会显示在界面中。

## 厂商入口隐藏

从后台导航中隐藏以下入口：

- 一号通配置。
- 短信购买及仅依赖一号通的厂商服务入口。
- 小程序下载。
- 主题市场外链入口。

采用展示层过滤：菜单接口数据进入前端后，根据稳定的组件路径过滤这些导航项。对应路由声明、Vue 页面、接口调用和后端权限不删除，直接路由仍保持可用。

“商城主题”“我的主题”等本地主题管理能力继续保留，只隐藏跳转 CRMEB 主题市场的推广入口。

## 非目标

- 不隐藏商品、订单、用户、内容、营销、分销、财务等商城业务模块。
- 不修改数据库菜单记录或系统配置记录。
- 不删除素材文件、Vue 页面、Java 接口或权限记录。
- 不批量修改源文件头部的许可与版权注释。

## 实现边界

- 品牌替换集中在当前实际渲染品牌内容的组件和默认值中。
- 菜单隐藏使用单一、可审计的厂商入口路径集合，避免散落条件判断。
- 被隐藏页面仍可通过直接 URL 加载，以证明业务逻辑未被移除。
- 注释只说明隐藏原因，不保留大段失效代码。

## 验证

1. 管理后台登录页不出现“开源版”“企业”“CRMEB”或版本号。
2. 登录后首页、浏览器标题和页脚不出现厂商品牌或版本信息。
3. 后台导航不出现一号通、短信购买、小程序下载和主题市场入口。
4. H5 个人中心不出现 CRMEB 厂商版权图片。
5. 被隐藏页面的直接路由仍能加载。
6. 管理后台与 H5 构建成功。
7. 运行针对登录页、首页、菜单和 H5 个人中心的浏览器回归检查。
