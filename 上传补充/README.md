# 项目补充备份

两份 Android APK、安装说明、校验文件和验收截图在仓库中保留原文件，可直接下载。

此前未上传的签名证书及签名密码信息、两份完整 SQL 备份、开发工具临时文件、依赖目录、构建产物、日志、测试产物和登录缓存，按原目录打包保存在本目录的加密分卷中。APK 的原始签名资料和 SQL 内容没有修改。

仓库为公开仓库，备份采用 AES-256 ZIP 加密。解密密码单独保存在交付电脑的 `上传补充/解密密码-仅本地.txt`，该文件不上传 GitHub。迁移备份时，请同时单独保存该密码。

## 还原

1. 下载本目录全部 `项目补充备份.zip.001`、`.002` 等分卷，以及 `备份校验.json` 和 `还原补充备份.py`，放在同一个目录。
2. 安装 Python 3.9 或更新版本，运行 `python3 -m pip install pyzipper`。
3. 运行 `python3 还原补充备份.py --output 补充备份还原`，按提示输入单独保存的解密密码。也可通过 `--password-file 解密密码-仅本地.txt` 从本地文件读取密码。
4. 工具会核对各分卷 SHA-256、合并分卷、解密并校验 `原始补充文件.tar.gz`。使用 7-Zip 解压该文件，或运行 `tar -xzf 原始补充文件.tar.gz -C 新建的还原目录`。

解压后，签名资料位于 `APK安装包/签名/`，完整数据库备份位于 `数据库导出/`；迁移数据库请阅读其中的 `最终SQL导入说明.md`。

构建产物与依赖来自本机 macOS 环境。恢复到其他操作系统时，以仓库源码和依赖配置重新安装、构建为准。
